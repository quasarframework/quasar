::: warning Warning! Beta Stage
The Quasar SSG Mode is currently in the "beta" stage. Based on the community feedback, the API may change in the future, so check the release notes each time you upgrade "@quasar/app-vite".
:::

When deploying as a SSG app, the distributables folder that gets generated by Quasar CLI can be served by a static webserver, just like a regular SPA.

Therefore, you can check out the [Deploying SPA](/quasar-cli-vite/developing-spa/deploying) page. The only things that differ is the build command (which for a SSG is "quasar build -m ssg" instead of just "quasar build") and that the distributables folder is "dist/ssg" instead of "dist/spa".
