# QList API

Type: component

Canonical documentation: https://quasar.dev/vue-components/list-and-list-items

## Props

### `bordered`

Type: `Boolean`

Applies a default border to the component

### `dense`

Type: `Boolean`

Dense mode; occupies less space

### `separator`

Type: `Boolean`

Applies a separator between contained items

### `dark`

Type: `Boolean | null`

Default: `null`

Notify the component that the background is a dark color

### `padding`

Type: `Boolean`

Applies a material design-like padding on top and bottom

### `tag`

Type: `String`

Default: `'div'`

Added in: v2.10.1

HTML tag to use

Examples:

- `'div'`
- `'ul'`
- `'ol'`

## Slots

### `default`

This is where the content goes; Suggestion: QItem, QExpansionItem, ...
