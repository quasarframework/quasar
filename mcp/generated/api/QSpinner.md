# QSpinner API

Type: component

Canonical documentation: https://quasar.dev/vue-components/spinners

## Props

### `size`

Type: `String | Number`

Default: `'1em'`

Size in CSS units, including unit name or standard size name (xs|sm|md|lg|xl)

Examples:

- `'16px'`
- `'2rem'`
- `'xs'`
- `'md'`

### `color`

Type: `String`

Color name for component from the Quasar Color Palette

Examples:

- `'primary'`
- `'teal'`
- `'teal-10'`

### `thickness`

Type: `Number`

Default: `5`

Override value to use for stroke-width
