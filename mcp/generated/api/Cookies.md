# Cookies API

Type: plugin

Canonical documentation: https://quasar.dev/quasar-plugins/cookies

## Methods

### `get`

Get cookie

### `getAll`

Get all cookies

### `set`

Set cookie

### `has`

Check if cookie exists

### `remove`

Remove a cookie

### `parseSSR`

For SSR usage only, and only on the global import (not on $q.cookies)
