# QItemLabel API

Type: component

Canonical documentation: https://quasar.dev/vue-components/list-and-list-items

## Props

### `overline`

Type: `Boolean`

Renders an overline label

### `caption`

Type: `Boolean`

Renders a caption label

### `header`

Type: `Boolean`

Renders a header label

### `lines`

Type: `Number | String`

Apply ellipsis when there's not enough space to render on the specified number of lines;

## Slots

### `default`

The content of the label; Suggestion: text
