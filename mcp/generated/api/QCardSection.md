# QCardSection API

Type: component

Canonical documentation: https://quasar.dev/vue-components/card

## Props

### `horizontal`

Type: `Boolean`

Display a horizontal section (will have no padding and can contain other QCardSection)

### `tag`

Type: `String`

Default: `'div'`

HTML tag to use

Examples:

- `'div'`
- `'form'`

## Slots

### `default`

Default slot in the devland unslotted content of the component
