# Dark API

Type: plugin

Canonical documentation: https://quasar.dev/quasar-plugins/dark

## Props

### `isActive`

Type: `Boolean`

Is Dark mode active?

### `mode`

Type: `Boolean | String`

Dark mode configuration (not status)

Accepted values: `'auto'`, `true`, `false`

## Methods

### `set`

Set dark mode status

### `toggle`

Toggle dark mode status
