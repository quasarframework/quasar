# QResizeObserver API

Type: component

Canonical documentation: https://quasar.dev/vue-components/resize-observer

## Props

### `debounce`

Type: `String | Number`

Default: `100`

Debounce amount (in milliseconds)

Examples:

- `0`
- `'530'`

## Events

### `resize`

Parent element has resized (width or height changed)

## Methods

### `trigger`

Emit a 'resize' event
