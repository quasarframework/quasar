# QBtnGroup API

Type: component

Canonical documentation: https://quasar.dev/vue-components/button-group

## Props

### `spread`

Type: `Boolean`

Spread horizontally to all available space

### `outline`

Type: `Boolean`

Use 'outline' design for buttons

### `flat`

Type: `Boolean`

Use 'flat' design for buttons

### `unelevated`

Type: `Boolean`

Remove shadow on buttons

### `rounded`

Type: `Boolean`

Applies a more prominent border-radius for squared shape buttons

### `square`

Type: `Boolean`

Added in: v2.7.6

Removes border-radius so borders are squared

### `push`

Type: `Boolean`

Use 'push' design for buttons

### `stretch`

Type: `Boolean`

When used on flexbox parent, buttons will stretch to parent's height

### `glossy`

Type: `Boolean`

Applies a glossy effect

## Slots

### `default`

Suggestion: QBtn
