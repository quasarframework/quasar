# QTabPanel API

Type: component

Canonical documentation: https://quasar.dev/vue-components/tab-panels

## Props

### `name`

Type: `Any`

Required: yes

Panel name

Examples:

- `'accounts'`
- `'firstPanel'`
- `1`

### `disable`

Type: `Boolean`

Put component in disabled mode

## Slots

### `default`

Default slot in the devland unslotted content of the component
