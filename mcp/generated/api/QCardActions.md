# QCardActions API

Type: component

Canonical documentation: https://quasar.dev/vue-components/card

## Props

### `align`

Type: `String`

Default: `# 'left'/'stretch'`

Specify how to align the actions; For horizontal mode, the default is 'left', while for vertical mode, the default is 'stretch'

Accepted values: `'left'`, `'center'`, `'right'`, `'between'`, `'around'`, `'evenly'`, `'stretch'`

### `vertical`

Type: `Boolean`

Display actions one below the other
