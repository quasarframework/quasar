# Quasar documentation artifact prototype

This directory contains Phase 1 of an AI-readable Quasar UI documentation artifact. It processes every public component, directive, plugin, and composable guide together with the resolved API definitions and associated examples.

## Immutability boundary

Everything outside this directory is an input and must remain unchanged. The generator:

- reads documentation and API files from the parent Quasar repository;
- writes only to `mcp/generated/`;
- records a SHA-256 digest for every consumed source file; and
- validates those digests after generation to detect accidental source changes.

The prototype is deliberately not registered in the root pnpm workspace. Run it independently:

```bash
node mcp/scripts/generate.js
node mcp/scripts/validate.js
node --test mcp/tests/*.test.js
node mcp/scripts/verify-immutability.js
```

The source repository can be supplied explicitly when testing the generator elsewhere:

```bash
node mcp/scripts/generate.js --source-root /path/to/quasar
node mcp/scripts/validate.js --source-root /path/to/quasar
```

## Generated artifact

The generator currently covers:

- 123 component APIs;
- 11 directive APIs;
- 18 plugin APIs;
- 11 public composables and their implementation sources; and
- every documentation page and example associated with those public contracts.

The generator produces:

- `generated/manifest.json` — artifact and source provenance;
- `generated/documents/**/*.md` — processed, self-contained documentation;
- `generated/documents/**/*.json` — structured page metadata;
- `generated/chunks/**/*.json` — retrieval-sized documentation sections;
- `generated/api/*.json` — resolved public APIs generated by Quasar UI;
- `generated/api/*.md` — LLM-readable renderings of those APIs;
- `generated/examples/**/*.vue` — examples referenced by the selected documentation pages;
- `generated/sources/composables/*.js` — public composable implementation sources;
- `generated/search-index.jsonl` — deterministic document, API, and example search records;
- `generated/llms.txt` — a compact artifact index for AI clients; and
- `generated/integrity.json` — source and output file hashes.

APIs are associated with pages through both explicit `<DocApi>` references and their canonical `docsUrl`. This includes public APIs that intentionally share a page without having a separate tag, such as spinner variants, `QSpace`, `QFormChildMixin`, `Meta`, and `QUploaderAddTrigger`.

This is an artifact-generation project only. It intentionally contains no MCP server or protocol dependency yet.
